# Ticket System (火车票管理系统)

## 📖 项目简介

这是一个基于命令行交互 (CLI) 的高性能火车票管理系统。该项目旨在模拟类 12306 的后端业务逻辑。

与传统基于内存的系统不同，本系统严格遵循“主体数据存储于外存”的性能要求。底层采用自行设计的 B+ 树结构，实现了在低内存占用下对海量数据的高效增删改查。

## ✨ 核心特性

### 业务功能

- 用户管理：支持完整的用户账户管理。
- 车次管理：管理员可以对车次进行维护。
- 车票查询：系统支持直达查询和换乘查询两种查询方式。
- 购票：系统支持直接购票和候补购票两种购票方式。

### 技术亮点

- 持久化存储：所有数据实时写入磁盘，系统崩溃不丢失数据。
- B+ 树 (B Plus Tree)：使用 B+ 树存储维持数据有序性。
- 缓存：采用缓存减少从磁盘读取数据的频率。

## 🛠️ 构建与运行

### 环境依赖

操作系统: Linux (推荐 Ubuntu) 或 Windows (WSL)

编译器: g++ (需支持 C++17 或更高版本)

构建工具: CMake

### 编译步骤

1. 克隆仓库

```shell
git clone https://github.com/xj22yangyichen/Ticket-System
cd "Ticket System"
```

2. 编译项目

```shell
mkdir build
cmake -B build
cmake --build build
```

### 运行方式

```shell
./build/code
```

随后程序进入命令交互模式，详见命令手册。

## 📘 命令手册

使用命令行（Terminal）进行操作，输入数据以换行符为分隔为若干指令。

指令格式遵循：`[<timestamp>] <cmd> -<key> <argument> ...`

| 命令类型 | 命令名称           | 常用度 | 功能描述                            |
| -------- | ------------------ | ------ | ----------------------------------- |
| **用户** | `add_user`         | [N]    | 注册新用户（首位用户权限为 10）     |
|          | `login` / `logout` | [F]    | 用户登录与登出                      |
|          | `modify_profile`   | [F]    | 修改用户信息（需权限校验）          |
| **车次** | `add_train`        | [N]    | 添加车次信息                        |
|          | `release_train`    | [N]    | 发布车次，发布后才可购票且不可删除  |
|          | `query_train`      | [N]    | 查询特定日期的车次详细信息          |
| **查询** | `query_ticket`     | [SF]   | 查询两站间的直达车票                |
|          | `query_transfer`   | [N]    | 查询一次换乘的最优方案              |
| **交易** | `buy_ticket`       | [SF]   | 购买车票，支持 `-q true` 候补       |
|          | `query_order`      | [F]    | 查看用户所有历史订单                |
|          | `refund_ticket`    | [N]    | 退订最近的第 n 个订单，触发候补重算 |
| **系统** | `clean` / `exit`   | [R]    | 清除所有文件数据 / 退出程序         |

具体的命令含义、参数和变量见 [业务要求](业务要求.md)。
